# 文档入口

- [当前状态](CURRENT.md)：现阶段、任务进度和授权边界。
- [PRD](product/PRD.md)：产品需求、AI 责任、业务流程、权限、状态、异常、F/AC/Q 与后续交接。
- [用户确认](product/用户确认.md)：用户明确方向和业务硬约束的整理记录。
- [UX 方案](design/UX方案.md)：Muse 式工作区、授权视图与准备层场景的纸面草案。
- [架构方案](architecture/架构方案.md)：竞赛轻部署、持久事项、权限、独立状态与恢复合同草案。
- [任务清单](product/任务清单.md)：阶段任务、依赖与实际状态。
- [会话交接](handoff/会话交接.md)：后续工作的恢复入口。
- [产品基线审查](evidence/产品基线审查.md)：本轮资料与需求检查，不能替代功能测试。
- [工程验证](evidence/工程验证.md)：本地准备层的实际HTTP检查、浏览器操作和未验证边界。

当前 PRD 与用户后续决定优先。用户确认、产品建议、待核业务口径和实际验证结果分别记录。

- [轻量启动](轻量启动.md)：无第三方依赖的本地启动、独立账号、一致备份与本地应用包。
